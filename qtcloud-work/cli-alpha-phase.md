# 量潮工作云命令行工具开始内测

量潮工作云命令行工具已于今天正式开始内测，在 crates.io 下载 qtcloud-work-cli 、系统内预装 pi 即可使用。

## 工作流是知识工作的第一等公民

在昨天的文章中，我们提到了最新的进展。

今天我们把方法落地成了完整的命令行工具。明天我们会继续把客户端也落地出来。

命令行工具本质上提供了一个给当前智能体按你的工作流要求调度子智能体的骨架。

你可以在上层使用任何一个智能体调用命令行。首先设计一个工作流并保存在你觉得合适的位置，然后使用这个工作流调度智能体工作并监督结果。

如果对工作结果满意，那么工作流文件保存下来即可继续重复使用。如果对某个具体产物不满意，也可以和 AI 提出你的想法，继续改进工作流并重复运行。

相比于看智能体心情触发和随时可能不遵守既定流程的 Skill，命令行通过调度规则引擎强制执行了工作流，并且在每一个步骤结束以后运行验收规则，从而最大限度确保不偏离人类预期。

如果你已经积累了大量的碎片化工作步骤，那么它可以帮助你看清这些工作步骤之间的关系，帮助你更好地整合这些步骤。

如果你有新的流程需要积累，那么它可以成为你很好的脚手架加快探索流程的步伐。

## 未来预期的商业模式

目前核心代码已经开源到 GitHub 仓库 quanttide/qtcloud-work。有条件的社区朋友可以自己部署使用，有反馈欢迎通过 GitHub issue 提交。

商业模式主要参考 Terraform Cloud 和 GitHub Actions，结合资源管理数量和任务调度数量计费。

未来我们会通过服务端托管工作流规格、产物规格等关键配置信息，并且根据规格的数量来定价，超出免费额度会按量计费。

预期我们的商业模式将不会是卖 Token 为主，因此我们对于用户接入自己的 API 保持开放态度。
